# 💶 MoneyWise — Управление на личен бюджет

Приложение за планиране и проследяване на личните финанси **в евро**: приходи и разходи, бюджети, спестовни цели и анализ с диаграми — включително **3D** елементи (Three.js).
Езици: **български (по подразбиране)** и **English** — превключвател BG / EN без загуба на данни.

## Стартиране
Статичен сайт без build стъпка:
```bash
python -m http.server 5173
```
после отворете http://localhost:5173. GitHub Pages се публикува автоматично от `.github/workflows/pages.yml`.

## Режими на данни
| Режим | Кога | Къде се пазят данните |
|---|---|---|
| **Демо** | `js/config.js` е празен | `localStorage` (предварително заредени демо данни) |
| **Supabase** | попълнени `SUPABASE_URL` и `SUPABASE_ANON_KEY` | PostgreSQL + Auth + Row Level Security |

За Supabase: изпълнете [`supabase/schema.sql`](supabase/schema.sql) в SQL Editor, попълнете `js/config.js`, регистрирайте се в приложението → „Настройки → Зареди демо данни“.

## Основни функции
- **Табло**: 3D въртяща се монета, 3D обръщаща се карта с баланс, KPI, паричен поток, индекс на здраве, дарт по категории, умни съвети, бързо въвеждане.
- **Транзакции**: CRUD, търсене, филтри, групиране по дни, маркер „необичайно“, експорт CSV.
- **Бюджети**: лимити по категории, прогрес, предупреждение при темп над лимита.
- **Цели**: пръстени на прогреса, вноски, конфети при постигане, умно разпределение на спестяванията.
- **Анализ**: интерактивна **3D** диаграма (месец × категория), капитал във времето, прогноза, календар-топлина, по дни от седмицата, топ места.
- **Настройки**: език, тема (тъмна/светла), JSON резервно копие/импорт, категории, демо данни.
- Клавиш **N** — нова транзакция.

## Собствени алгоритми ([`js/algo.js`](js/algo.js))
1. **Прогноза за края на месеца** — EMA(45 дни) + фиксирани/променливи разходи + winsorizing.
2. **Индекс на финансово здраве 0–100** — спестяване (35%), бюджет (30%), стабилност (15%), цели (20%).
3. **Умно разпределение на спестяванията** — нужда = оставащо ÷ месеци; тегло = нужда × приоритет.
4. **Откриване на аномалии** — modified z-score (медиана + MAD).
5. **Разпознаване на естествен текст** — „кафе 4.50 вчера“ → сума, категория, дата.

Тестове: `node tests/algo.test.js` (14 теста). Подробности — [docs/TESTS.md](docs/TESTS.md).
