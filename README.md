# 💶 MoneyWise — Управление на личен бюджет

Уеб приложение за планиране и проследяване на личните финанси **в евро**: приходи, разходи, категории, бюджети, спестовни цели, месечни отчети и диаграми (включително 3D с Three.js).
Езици: **български (по подразбиране)** и **English** — бутон BG / EN, без загуба на данни.

**Екип:** Адам Биков (Ученик 1 — интерфейс) · Реджеб Туджар (Ученик 2 — данни и алгоритъм)

## Стартиране
Статичен сайт без build стъпка:
```bash
cd src
python -m http.server 5173
```
Отворете http://localhost:5173. GitHub Pages публикува папката `src/` чрез `.github/workflows/pages.yml`.

## Режими на данни
| Режим | Кога | Къде се пазят данните |
|---|---|---|
| **Демо** | `src/js/config.js` е празен | `localStorage` (реалистични демо данни, без лична информация) |
| **Supabase** | попълнени `SUPABASE_URL` и `SUPABASE_ANON_KEY` (вж. `.env.example`) | PostgreSQL + Auth + Row Level Security |

За Supabase: изпълнете [`database/schema.sql`](database/schema.sql) в SQL Editor, попълнете `src/js/config.js`, регистрирайте се в приложението → „Настройки → Зареди демо данни“.

## Функции
- **Табло:** 3D монета, 3D карта с баланс, KPI, паричен поток, индекс на здраве, дарт по категории, умни съвети, бързо въвеждане („кафе 4.50“).
- **Транзакции:** CRUD, търсене, филтри, CSV експорт, маркер „необичайно“.
- **Бюджети:** лимити по категории, прогрес, предупреждения.
- **Цели:** пръстени на прогреса, вноски, умно разпределение на спестяванията.
- **Анализ:** 3D диаграма, прогноза, календар-топлина, по дни от седмицата.
- **Настройки:** език, тема, резервно копие JSON, категории.

## Собствени алгоритми ([`src/js/algo.js`](src/js/algo.js), [описание](docs/ALGORITHM.md))
