# TEACHER_TEST — как учителят проверява реализираната функция

**Проект:** MoneyWise · **Екип:** Адам Биков и Реджеб Туджар

## Вариант А — без никаква настройка (демо режим)
Работи веднага; данните са измислени и се пазят в браузъра.

1. Изтеглете хранилището (или ZIP) и в терминал изпълнете:
   ```bash
   cd src
   python -m http.server 5173
   ```
2. Отворете http://localhost:5173 — зарежда се на **български**; за английски: бутон **EN** (или адрес `?lang=en`).
3. Налични са реални тестови данни (33 транзакции, 7 бюджета, 3 цели).

### Функцията за проверка: „Транзакции“ (четене + добавяне + редакция + изтриване + търсене)
| Стъпка | Очакван резултат |
|---|---|
| Меню **Транзакции** | списък по дни за избрания месец, суми в евро |
| Поле за търсене → „Lidl“ | остават само записи с Lidl |
| Филтър „Всички категории“ → „Храна“ | само разходи за храна |
| **Нова транзакция** → сума `4.50`, бележка „Кафе“ → **Запази** | записът се появява най-горе; „Разходи“ и „Брой“ се увеличават |
| Бутон „молив“ на записа → смяна на сумата → Запази | сумата се променя |
| Бутон „кошче“ → потвърждение | записът изчезва |
| Празна сума или 0 | съобщение за грешка, записът не се създава |
| Смяна BG ↔ EN при отворена форма/въведен текст | интерфейсът се превежда, въведените данни остават |
| Меню **Бюджети** | втори екран: лимити, прогрес, предупреждения |
| Ширина на прозореца ~390 px (DevTools → телефон) | долна навигация, без хоризонтален скрол |

## Вариант Б — със Supabase (реална база данни)
Тестови достъп: ☐ *(екипът попълва: линк към демото/хранилището и тестов акаунт, напр. `teacher-test@example.com` / парола, която е само за тази проверка)*.

1. В `src/js/config.js` са вписани `SUPABASE_URL` и publishable ключ *(не се съхраняват тайни ключове; RLS е включен)*.
2. Приложението показва екран за **вход** → влезте с тестовия акаунт.
3. Повторете стъпките от варианта по-горе — записите се пазят в таблица `transactions` в Supabase (виждат се в Table Editor).
4. Структурата на таблиците и връзките: `docs/ER_DIAGRAM.md` и снимките в `docs/screens/etap2/supabase/`.
