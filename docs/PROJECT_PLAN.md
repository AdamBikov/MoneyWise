# PROJECT_PLAN — MoneyWise

## Функционалности (поне 5 задължителни)
1. Приходи и разходи — CRUD с валидация.
2. Категории — вградени + собствени.
3. Месечни бюджети с предупреждения.
4. Спестовни цели с вноски.
5. Месечен отчет и диаграми (SVG, 3D с Three.js).
6. Вход/регистрация (Supabase Auth) и RLS.
7. Двуезичност BG/EN, светла/тъмна тема.

## Собствен алгоритъм: прогноза на остатъка + превишен бюджет
| | |
|---|---|
| **Входни данни** | транзакции на потребителя, категории, бюджети, текуща дата |
| **Обработка** | 1) разделя разходите на фиксирани и променливи; 2) дневен темп = 0.6·EMA(45 дни) + 0.4·средно за месеца (еднократните големи покупки се ограничават); 3) прогноза = направено + предстоящи фиксирани + темп × оставащи дни; 4) за всеки бюджет: линейна проекция на темпа → статус `ok / warning / risk / exceeded` и ден на изчерпване |
| **Резултат** | прогнозиран разход и нетен остатък в края на месеца; списък с бюджети със статус; съвети на таблото |

Подробности, гранични случаи, сложност и ръчни примери: [ALGORITHM.md](ALGORITHM.md).

## Технологии
HTML5, CSS3, JavaScript (ES2020), Supabase (PostgreSQL, Auth, RLS), GitHub + GitHub Pages.

**Допълнителни библиотеки (обосновка):**
- *Three.js* — 3D визуализации, които правят анализа по-нагледен и ангажиращ.
- *supabase-js* — официалният клиент за Auth и база данни.
- 2D диаграмите са собствен SVG код (по-малко зависимости, пълен контрол). Заданието препоръчва Chart.js и Vitest — приемливи алтернативи; засега тестовете ползват вградения `node:assert`.
