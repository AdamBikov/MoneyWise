# План на проекта MoneyWise

**Цел:** приложение за личен бюджет в евро с приходи/разходи, бюджети, цели и анализ.

## Функционалности
CRUD транзакции · категории · месечни бюджети · спестовни цели · диаграми (SVG + 3D Three.js) · прогноза · индекс на здраве · умно разпределение на спестяванията · откриване на аномалии · бързо въвеждане с естествен текст · BG/EN · светла/тъмна тема · експорт CSV/JSON.

## Технологии
HTML5, CSS3 (glassmorphism, 3D transforms), JavaScript (ES2020), Three.js r128, Supabase (PostgreSQL, Auth, RLS), GitHub Pages.

## Архитектура
`i18n` (преводи) → `store` (Supabase | localStorage, общ интерфейс) → `algo` (чисти функции) → `charts`/`scene` (визуализации) → `app` (изгледи).

## ER диаграма
[supabase/ER.md](../supabase/ER.md) — `categories`, `transactions`, `budgets`, `goals`, `goal_contributions`.
