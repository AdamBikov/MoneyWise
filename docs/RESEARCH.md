# Проучване на три сходни проекта

| | **YNAB / Monarch (Mint-подобни)** | **Wallet by BudgetBakers** | **Spendee** |
|---|---|---|---|
| Идея | Бюджети по категории, автоматизация | Мултивалутен портфейл, споделени бюджети | Визуален тракер с категории |
| Силни страни | Богат анализ | Много интеграции, цели | Красив интерфейс, лесно въвеждане |
| Слаби страни | Платени, без български/евро фокус | Сложен интерфейс | Ограничени безплатни функции |
| Какво взимаме | Бюджети, прогнози | Цели със срок | Бързо въвеждане, ясни диаграми |

**Вдъхновение за MoneyWise:** безплатно, двуезично (BG/EN), в евро, с *обясними собствени алгоритми* (прогноза, индекс на здраве, умно разпределение) и 3D визуализации. Изводите са по публични описания на продуктите (виж SOURCES).
