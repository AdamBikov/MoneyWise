# Ръководство за потребителя

1. **Език/тема** — BG / EN и бутон за тема (долу вляво; на телефон — горе).
2. **Табло** — общ баланс (щракни картата за обръщане), KPI за избрания месец, диаграми и съвети. Месецът се сменя със стрелките.
3. **Бързо въвеждане** — в лентата „⚡“: `кафе 4.50`, `+заплата 1800`, `такси 7 вчера`.
4. **Транзакции** — „＋ Нова транзакция“ (или клавиш **N**), търсене, филтри, ✏️ редакция, 🗑 изтриване, ⬇ CSV.
5. **Бюджети** — месечен лимит по категория; жълто над 85%, червено при надхвърляне.
6. **Цели** — сума и срок, вноски. „Умно разпределение“ предлага колко да отделяш на всяка цел.
7. **Анализ** — влачи 3D диаграмата за въртене; задръж върху стълб за сума.
8. **Настройки** — JSON резервно копие/импорт, категории, демо данни.
