# ALGORITHM — прогноза на остатъка и превишен бюджет

Код: [`src/js/algo.js`](../src/js/algo.js) — функции `forecast()` и `budgetAlerts()`. Тестове: [`tests/algo.test.js`](../tests/algo.test.js).

## 1. forecast(transactions, categories, today)
**Вход:** списък транзакции `{type, amount, tx_date, category_id}`, категории (фиксираните са с `key = 'housing'`), дата.
**Стъпки:**
1. `d` = ден от месеца, `rem` = оставащи дни.
2. Променливите разходи (без жилище) за последните 45 дни се сумират по дни; големите еднократни стойности се ограничават до `4 × медиана` (winsorizing).
3. `EMA` с α = 0.12 върху дневните стойности.
4. Дневен темп `rate = 0.6·EMA + 0.4·(променливи за месеца / d)`.
5. Фиксирани очаквани = `max(направено, миналия месец)`.
6. `projectedExpense = разходи досега + (фиксирани очаквани − направени) + rate·rem`.
7. `expectedIncome` = приходи от миналия месец, чиято категория още не е получена и чийто ден е след днешния.
8. `projectedNet = приходи + expectedIncome − projectedExpense`.

**Изход:** `{rate, remainingDays, projectedExpense, expectedIncome, projectedNet}`.
**Гранични случаи:** нов потребител без история (темп 0), последен ден от месеца (rem = 0), месец без приходи, еднократна голяма покупка (ограничена).
**Сложност:** O(n) по броя транзакции (n) + O(45) за EMA.

## 2. budgetAlerts(spentByCategory, budgets, today, month)
**Вход:** похарчено по категория за месеца, бюджети `{category_id, limit_amount}`, дата, месец.
**Стъпки (за всеки бюджет):**
1. `d` = днешен ден (за минал месец — целият месец), `dim` = дни в месеца.
2. `projected = spent / d · dim` (линейно продължение на темпа; за приключил месец = spent).
3. Статус: `exceeded` ако spent > limit; иначе `risk` ако projected > limit; иначе `warning` ако spent ≥ 85% от limit; иначе `ok`.
4. `exhaustDay = ⌈limit / (spent / d)⌉` — денят, в който бюджетът ще свърши (ако е в рамките на месеца).

**Изход:** списък `{budget, spent, limit, projected, status, exhaustDay, pct}`.
**Гранични случаи:** spent = 0 (статус ok, без ден на изчерпване), limit = 0 (pct = 0), ден 1 от месеца (d се ограничава до ≥ 1), минал месец.
**Сложност:** O(B), B = брой бюджети.

## Ръчни примери за проверка (15 ноември, месецът има 30 дни)
| # | Бюджет | Похарчено | Изчисление | Очакван резултат |
|---|---|---|---|---|
| 1 | 300 € | 320 € | 320 > 300 | `exceeded` |
| 2 | 300 € | 160 € | 160/15·30 = 320 > 300 | `risk` |
| 3 | 300 € | 150 € | 150/15·30 = 300 (не > 300); 150 < 255 | `ok`, ден на изчерпване = ⌈300/10⌉ = 30 |

Тези примери са покрити с автоматични тестове (`node tests/algo.test.js` — 20 теста).
